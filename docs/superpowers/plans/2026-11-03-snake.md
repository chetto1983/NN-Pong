# Snake Implementation Plan

> **For agentic workers:** Use the execution and verification skills; tasks have separate file ownership.

**Goal:** Aggiungere Snake Classic in Pygame, grafica del riferimento e controllo tramite pesi analitici.

**Architecture:** CLI `snake.py`, package `snake_game` con `network.py`, `simulation.py`, `app.py`; asset e JSON dei pesi locali. La simulazione riceve le azioni dai logits della rete.

**Tech Stack:** Python 3.12+, NumPy, Pygame; unittest esistente.

**Spec:** `docs/superpowers/specs/2026-11-03-snake-design.md`.

## Global Constraints

- Python/Pygame nella repository attuale; nessun training e nessun solver esterno durante il gioco.
- Grafica Classic/Sunset misurata sul sito; asset locali e fonti documentate.
- Interfaccia della rete: `SnakeNet(cols=18, rows=14).forward(x, y)` restituisce quattro logits in ordine UP, RIGHT, DOWN, LEFT.
- `SnakeSimulation(seed=0, cols=18, rows=14, net=None)` espone `body` (testa prima), `food`, `score`, `steps`, `status`, `direction`, `last_logits`; `step(action=None)` restituisce `running`, `won` o `dead`.

## Review Focus

- Il controllore deve essere interamente espresso da matrici/ReLU, senza fallback di guida.
- Ogni cella deve appartenere a un unico ciclo di mosse adiacenti e legali.
- Mangiare, entrare nella cella appena liberata dalla coda e riempire il campo devono rispettare le regole.
- Caricamento dei pesi deve rifiutare dati incoerenti/non finiti.
- I controlli visibili devono funzionare e la grafica deve essere confrontata con le acquisizioni.

## Risultati verificati

- Suite finale: **54/54 test passati** su Python 3.13/Windows, compresi i test Pong.
- `python snake.py --test`: ciclo completo di 252 celle e vittoria dopo 248 mele;
  seed 0 completato in 14.169 mosse.
- `python snake.py --headless --seeds 100 --json`: 100 vittorie, zero collisioni,
  zero timeout, 248 mele per partita, 1.546.524 mosse totali (media 15.465,24).
- JSON incluso caricato e provato sul seed 42: vittoria in 15.698 mosse.
- Windows nativo: rendering, pausa/ripresa, aiuto, reset, ridimensionamento,
  click e uscita; rendering aggiuntivo a 100 mele.
- `design-qa.md`: passed. Restano soltanto lievi differenze P3 di antialiasing,
  riflessi e ombre tra Canvas e Pygame.
- Revisione indipendente: nessun problema critico/importante; due rilievi UI
  minori corretti con regressioni RED→GREEN e suite finale completa.
- Il font WOFF2 non era compatibile con SDL_ttf: convertito lo stesso font in
  TTF, senza cambiare glifi. Nessuna nuova dipendenza di runtime.
